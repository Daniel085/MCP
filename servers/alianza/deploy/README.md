# Client configuration for alianza-mcp

Most customers should use `alianza-mcp install claude-code` or `install claude-desktop`, which write these for you. The files here show what gets written, for review or manual setup. No credentials appear in them: the server reads `~/.config/alianza-mcp/config.json`.

| File | Client |
| --- | --- |
| `mcp.json.example` | Claude Code, project scope (`.mcp.json`) |
| `claude_desktop_config.example.json` | Claude Desktop |
